The book dialog

One dialog in place of three. Open and Close sit in a bar at the top. The details and the cover are one form in the middle, open from the start and saved together. Who is reading the book, its file and what can be done with the file sit at the foot.

The frames work. Try Look up online, Choose an image, Close, and the options button on another book. The books, readers and matches are examples.

What changes in how it works

  • One Save. A cover that is chosen, pasted, dropped, taken from a page of the PDF or from a match shows at once in the dialog, marked as not saved yet, and is kept together with the details. Today each change of cover is saved at once.
  • Close leaves without saving, like Cancel today.
  • Paste and drop of an image work whenever the dialog is open, not only in the cover dialog.
  • Look up online works as today. A cover taken from a match shows in the cover's place.
  • The server gains one thing: it can show the cover in the book's file while the library shows another, so Use the original cover can be seen before it is saved. Save sends the same two requests as today, the cover and then the details.

Decided

  • One Save for the cover too. Nothing about a book changes until Save.
  • Readers are listed at the foot, without a button to ask for them.
  • Delete sits at the foot on the right, opposite Download, and still asks first.
  • Save sends only what was changed. A new cover alone leaves the details as the book's file has them, so converting the book again can still bring them up to date.
