Settings

This device

Theme, text size and weight, margins and line spacing are stored on each device separately, so your e-reader, phone and laptop can each look the way you want.

Text size and weight, margins and line spacing are changed from inside the reader (the Aa button).

Reload

Added to the home screen, the app has no browser button to reload it. This starts it again from the library, with the newest version of the app. In a book, the Aa button has a Reload too.

Account

Your font is used on all your devices. You can also change it from the Aa button in the reader.

Password changed.

Catalogues

Book details and covers come from Open Library, which needs no key, and from Hardcover when the server has a token for it. Hardcover knows series and their order well, and tells the library which books a series lacks. Make a token at hardcover.app (read:catalog is enough), paste it here, and it is used at once. It is kept on this server, in the database.

Offline

Every book you open is kept on this device, so you can read it without a connection. Offline, the library fades the books that aren't here. Reading positions sync when you are back online.
